### 🧬 Languages
*   **C++** — Primary weapon for high-performance software and memory manipulation.
*   **Assembly (x86/x64)** — Reading the matrix directly from the metal.
*   **Python** — Scripting automation, IDAPython extension, and rapid prototyping.

### 💻 Development & Environments
*   **Neovim (Neovide)** — Ultra-fast, keyboard-driven modal editor for clean codebases.
